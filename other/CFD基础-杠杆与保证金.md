# CFD 基础：杠杆与保证金

> 🎯 **新人导读**：杠杆和保证金是客户最常问的话题，也是强平的直接原因，务必熟悉 Margin Call 和 Stop Out 的触发条件。

## 杠杆（Leverage）

杠杆允许交易者用少量资金控制更大规模的头寸。

**杠杆表示方式**：
- 比例式：1:100（即 1 份保证金控制 100 份头寸）
- 百分比式：1%（即 1% 保证金率，等同于 1:100 杠杆）

**公式**：
```
杠杆 = 头寸总价值 / 所需保证金
```

**示例**：
- 交易 1 手 EUR/USD（$100,000）
- 杠杆 1:100 → 所需保证金 = $100,000 / 100 = **$1,000**
- 杠杆 1:30 → 所需保证金 = $100,000 / 30 = **$3,333**

## 保证金（Margin）

### 什么是保证金

保证金是开仓时必须在账户中持有的**最低资金**，作为潜在亏损的担保。保证金不是费用，而是临时冻结的资金。

### 保证金类型

| 类型 | 说明 |
|------|------|
| **已用保证金（Used Margin）** | 当前所有持仓已占用的保证金总额 |
| **可用保证金（Free Margin）** | 账户净值 - 已用保证金，可用于开新仓 |
| **账户净值（Equity）** | 账户余额 + 当前浮动盈亏 |
| **保证金水平（Margin Level）** | Equity / Used Margin × 100%，反映账户健康程度 |

### 保证金计算公式

```
所需保证金 = 头寸名义价值 / 杠杆倍数
头寸名义价值 = 手数 × 合约大小 × 当前价格
```

**外汇示例**（1 手 GBP/USD，杠杆 1:100，当前价 1.2500）：
```
名义价值 = 1 × 100,000 × 1.2500 = $125,000
所需保证金 = $125,000 / 100 = $1,250
```

## 保证金追加（Margin Call）

当账户净值下降，保证金水平跌至预设阈值时，券商会发出 **Margin Call**（保证金追加通知）。

- **含义**：账户资金不足以维持当前持仓
- **触发条件**：保证金水平跌至券商设定的 Margin Call 水平（如 100%）
- **处理方式**：追加资金，或主动减仓降低已用保证金

## 强平（Stop Out）

若账户继续亏损，保证金水平继续下跌，到达 **Stop Out 水平**时，券商系统将**自动平仓**，从亏损最大的持仓开始，直到保证金水平回到安全区间。

| 参数 | 说明 |
|------|------|
| Margin Call 水平 | 发出警告的保证金水平（如 100%） |
| Stop Out 水平 | 触发自动平仓的保证金水平（如 50%） |

**强平流程**：
1. 系统检测到保证金水平 ≤ Stop Out 水平
2. 自动平掉亏损最大的持仓
3. 平仓后重新计算保证金水平
4. 若仍低于 Stop Out → 继续平仓，直到恢复

> ⚠️ **重要**：强平不保证按止损价成交，极端行情下可能发生**负余额**（账户亏损超过存款）。正规券商通常提供**负余额保护**政策。

## 杠杆与风险的关系

杠杆是双刃剑：

| 杠杆 | 价格变动 1% | 保证金回报率 | 保证金亏损率 |
|------|------------|------------|------------|
| 1:10 | 盈利 10% | | |
| 1:50 | 盈利 50% | | |
| 1:100 | 盈利 100% | 全额亏损 | |

**监管规定的零售杠杆上限（ESMA/FCA/ASIC）**：
- 主要货币对：1:30
- 非主要货币对：1:20
- 主要股指：1:20
- 黄金：1:20
- 个股 CFD：1:5

> 专业客户（Professional Client）可申请更高杠杆，但需满足相关条件。
