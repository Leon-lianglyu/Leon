# MT4/MT5 Symbol 规格字段说明

> 🎯 **新人导读**：查看客户合约规格表（wiki 里的月度合约规格）时，这里解释每个字段的含义，也是 IB 返佣计算中「点值」的来源。

## 如何查看 Symbol 规格

- **MT4**：在 Market Watch 右键点击品种 → 「Specification（属性）」
- **MT5**：在 Market Watch 右键点击品种 → 「Specification」，或菜单栏 View → Symbols → 选中品种 → Properties

---

## 字段详解

### 一、价格与精度

| 字段 | 英文名 | 说明 |
|------|--------|------|
| **小数位数** | Digits | 报价的小数点后位数。外汇主流对通常为 5 位（如 1.08524），日元对为 3 位（如 151.234），黄金通常为 2 位。 |
| **点（Point）** | Point | 报价的最小变动单位 = `10^(-Digits)`。5 位报价的 point = 0.00001。**注意：Point ≠ Pip。** 1 Pip = 10 Points（5位报价品种）。 |
| **Tick Size** | Tick Size | 价格实际可变动的最小步长（单位：点）。大多数外汇品种 Tick Size = Point，但某些指数品种 Tick Size 可能更大（如 SP500 的 Tick Size = 0.1）。 |

---

### 二、合约与交易量

| 字段 | 英文名 | 说明 |
|------|--------|------|
| **合约大小** | Contract Size | 1 手（1 lot）代表的标的资产数量。外汇标准：100,000 单位基础货币；黄金（XAUUSD）：100 盎司；原油（USOIL）：1,000 桶；股指：通常 1 点。 |
| **最小手数** | Min Volume | 单笔订单允许的最小交易量（手数）。常见为 0.01 手。 |
| **最大手数** | Max Volume | 单笔订单允许的最大交易量（手数）。 |
| **手数步长** | Volume Step | 下单量的最小递增单位，通常为 0.01 手（即不能下 0.015 手，只能下 0.01 或 0.02）。 |

---

### 三、点值（Tick Value）

| 字段 | 英文名 | 说明 |
|------|--------|------|
| **盈利 Tick 值** | Tick Value (Profit) | 价格朝有利方向变动 1 个 Tick 时，1 手头寸的盈亏金额（账户货币计）。这是计算实际盈亏和返佣的核心参数。 |
| **亏损 Tick 值** | Tick Value (Loss) | 价格朝不利方向变动 1 个 Tick 时的盈亏。大多数品种与盈利 Tick 值相同；某些期货品种可能不同。 |

> **关系公式**：`盈亏 = 手数 × 价格变动（点数）÷ Tick Size × Tick Value`
>
> **简化版（Tick Size = Point 时）**：`盈亏 = 手数 × 价格变动（点数） × (Tick Value ÷ Tick Size)`

**举例（EURUSD，账户 USD）**：
- Contract Size = 100,000；Tick Size = 0.00001；Tick Value = 1 USD
- 买入 1 手，价格上涨 10 pips（= 100 points）
- 盈利 = 1 × 100 × (1 ÷ 0.00001) × 0.00001 = 1 × 100 × 1 = **100 USD**

**举例（USDJPY，账户 USD，汇率 150）**：
- Contract Size = 100,000 JPY；Tick Value ≈ 0.00667 USD（= 1 JPY ÷ 150）
- 买入 1 手，价格上涨 10 pips（= 100 points，因 3 位小数）
- 盈利 = 1 × 100 × (0.00667 ÷ 0.001) = 1 × 100 × 6.67 ≈ **667 USD**

---

### 四、点差（Spread）

| 字段 | 英文名 | 说明 |
|------|--------|------|
| **点差** | Spread | Bid 价与 Ask 价之差，单位为 Points（最小点）。浮动点差（Float Spread）会随市场流动性变化。 |
| **是否浮动点差** | Spread Float | 标记该品种是否为浮动点差。STP/ECN 账户通常为浮动点差；固定点差账户此项为 false。 |

> **换算**：合约规格表中「浮动点差」列的数值单位为 Points（最小点），计算时须乘以 Tick Value。

---

### 五、保证金（Margin）

| 字段 | 英文名 | 说明 |
|------|--------|------|
| **初始保证金** | Initial Margin | 开仓 1 手所需的初始保证金（账户货币）。若为 0 表示采用杠杆模式计算（见下）。 |
| **维持保证金** | Maintenance Margin | 维持持仓所需的最低保证金；低于此值触发 Margin Call。通常 = 初始保证金 × 50%（各经纪商不同）。 |
| **对冲保证金** | Hedged Margin | 对冲仓位（同品种反向持仓）所需的保证金，通常低于单向持仓的保证金。 |
| **保证金计算模式** | Margin Mode | Forex 模式：`保证金 = 手数 × Contract Size ÷ 杠杆`；CFD 模式：`保证金 = 手数 × Contract Size × 开仓价 × 保证金比例`。 |

---

### 六、库存费（Swap）

| 字段 | 英文名 | 说明 |
|------|--------|------|
| **多仓库存费** | Swap Long | 持有多仓过夜收取/支付的费用。正数为收入，负数为支出。 |
| **空仓库存费** | Swap Short | 持有空仓过夜收取/支付的费用。 |
| **库存费模式** | Swap Mode | 计算方式：以点计（Points）、以货币计（Currency）、以百分比年化计（Interest %）等。 |
| **三倍 Swap 日** | Triple Swap Day | 某日的库存费会乘以 3，用于补偿周末两天。外汇通常为周三；黄金、部分指数为周五。 |

---

### 七、止损与冻结距离

| 字段 | 英文名 | 说明 |
|------|--------|------|
| **止损距离** | Stops Level | 止损（SL）和止盈（TP）必须距当前市价的最小距离（单位：Points）。若设置过近会被拒绝。Stops Level = 0 表示无限制。 |
| **冻结距离** | Freeze Level | 当市价进入此距离范围内时，挂单的修改/删除操作会被冻结，防止在临近触发时干预。单位：Points。大多数现货 FX 品种为 0。 |

---

### 八、执行模式

| 模式 | 说明 |
|------|------|
| **Market Execution** | 以当前最优市价成交，无重新报价；STP/ECN 账户常见，会有滑点。 |
| **Instant Execution** | 以请求价成交；若市价偏离超过允许范围，经纪商可重新报价（Requote）；旧式 MM 账户常见。 |
| **Exchange Execution** | 以交易所撮合价成交，用于股票/期货等。 |
| **Request Execution** | 先请求报价，确认后成交。 |

---

## 与 UM 合约规格表的对应

UM 合约规格表各列对应关系：

| UM 规格表列名 | 对应 MT4/MT5 字段 |
|-------------|-----------------|
| 小数点位 | Digits |
| 每手合约大小 | Contract Size |
| 浮动点差（仅供参考） | Spread（Points） |
| 最小手数 | Min Volume |
| 最大手数 | Max Volume |
| 手数步长 | Volume Step |
| 买入库存费 | Swap Long |
| 卖出库存费 | Swap Short |
| 三倍库存费日 | Triple Swap Day |
