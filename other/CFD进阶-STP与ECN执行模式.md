# CFD 进阶：STP 与 ECN 执行模式

> 🎯 **新人导读**：这是理解 IB 返佣结构的核心背景——为什么 STP 账户用 pips 计算返点、ECN 账户用 USD 计算佣金，答案在这里。

## 为什么理解 STP vs ECN 很重要

UM 的两种主账户类型（Standard STP 和 Raw ECN）在盈利来源、点差、手续费、IB 返佣计算方式上均不同。理解执行模式的行业背景，有助于解释为何 IB 返佣规则中 STP 按「pips」计算而 ECN 按「USD/手」计算。

---

## STP（Straight Through Processing，直通处理）

### 定义

STP 是指客户的交易指令**直接路由至流动性提供商**（银行、做市商等），不经过任何中间人干预。经纪商不充当交易对手方，也不持有反向仓位。

### 盈利模式

STP 经纪商通过**在原始点差上加宽（Markup）**来盈利：

```
客户看到的点差 = 原始流动性点差 + Markup（加点）
```

- 点差宽窄随市场流动性变动（变动点差）
- 经纪商的收入 = Markup 部分，与客户盈亏无关
- IB 返佣从 Markup 中分出一部分给 IB → 这就是为什么 STP 返佣用「pips」衡量

### UM Standard STP 账户特点

| 特征 | 说明 |
|------|------|
| 点差 | 含 Markup 的变动点差（通常 1.0–2.5 pips 起） |
| 额外手续费 | 无 |
| 加点上限 | 最高 2 pips（超过须 Lark 人工申请） |
| IB 返佣单位 | pips/手（FX/Oil/Gold/Silver）或 %（其他品种） |

---

## ECN（Electronic Communications Network，电子通讯网络）

### 定义

ECN 将所有参与者（银行、做市商、机构、散户）的订单汇聚到同一个电子化交易池，买卖双方**直接撮合**。经纪商从每笔成交中收取**固定手续费（Commission）**，不从点差中赚差价。

### 盈利模式

```
客户交易成本 = 原始点差（接近 0）+ 固定手续费
```

- 点差极低（外汇通常 0.0–0.5 pips 原始点差）
- 经纪商收入 = 每手固定佣金，与点差无关
- IB 返佣从手续费中分出 → 这就是为什么 ECN 返佣用「USD/手」衡量

### UM Raw ECN 账户特点

| 特征 | 说明 |
|------|------|
| 点差 | 接近原始市场点差（0.0 pips 起） |
| 手续费 | 固定（USD 账户 5 USD/手单边，即 10 USD 双边） |
| 加佣上限 | 最高 20 USD（加佣越高，IB 手数佣金越低） |
| MT4 执行 | 开仓时附加订单，平仓时才从余额扣除 |
| MT5 执行 | 开仓扣 50%，平仓扣剩余 50% |
| IB 返佣单位 | USD/手（FX/Oil/Gold/Silver）或 %（其他品种） |

---

## STP vs ECN 对比

| 维度 | Standard STP | Raw ECN |
|------|-------------|---------|
| 点差 | 较宽（含 Markup） | 极窄（接近原始） |
| 手续费 | 无 | 有（固定 USD/手） |
| 总交易成本 | 仅点差 | 点差 + 手续费 |
| 适合交易风格 | 低频、中长线 | 高频、短线、剥头皮 |
| IB 返佣计算 | pips/手 | USD/手 |
| 经纪商收入来源 | 点差 Markup | 固定手续费 |

---

## 为什么 STP 和 ECN 返佣必须同级别申请

IB 返佣按「累计入金」分 5 档（1–49,999 / 50,000–99,999 / 100,000–199,999 / 200,000–499,999 / 500,000+），每档对应一组 STP pips 和 ECN USD 数值。

由于两种账户类型最终代表相同的「IB 成本」等级，**同一个 IB 下的 STP 和 ECN 必须选择对应同一档位**，否则利润分配逻辑错乱。
