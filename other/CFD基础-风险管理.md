# CFD 基础：风险管理

> 🎯 **新人导读**：这是向客户科普风控意识的背景知识，也涉及负余额保护政策（UM 的穿仓清零规则与此相关）。

## 止损（Stop Loss）

**定义**：预先设定的平仓价格，当持仓亏损达到该价格时自动平仓，防止亏损继续扩大。

**类型**：

| 类型 | 说明 | 特点 |
|------|------|------|
| 普通止损（Standard SL） | 触发后以市价执行 | 极端行情下可能滑点 |
| 保证止损（Guaranteed SL） | 保证以设定价格成交 | 通常额外收费，但无滑点风险 |
| 移动止损（Trailing SL） | 随盈利方向自动移动 | 锁定盈利，见[[CFD基础-订单类型]] |

**设置止损的原则**：
- 止损应设在技术上有意义的位置（支撑/阻力位之外），而非随意百分比
- 避免止损过近（容易被市场噪音触发）或过远（亏损过大）

## 止盈（Take Profit）

**定义**：预先设定的平仓价格，当持仓盈利达到该价格时自动平仓，锁定利润。

**注意**：设置止盈不是必须的，可以手动观察平仓；但预设止盈有助于避免贪婪情绪干扰决策。

## 风险回报比（Risk-Reward Ratio）

```
风险回报比 = 止盈点数 / 止损点数
```

**示例**：
- 止损 50 pips，止盈 100 pips → 风险回报比 1:2
- 即使胜率只有 40%，长期期望值仍为正：0.4 × 100 - 0.6 × 50 = +10 pips

**行业惯例**：建议风险回报比至少为 1:1.5 或 1:2，即盈利目标至少为潜在亏损的 1.5–2 倍。

## 仓位管理（Position Sizing）

**核心原则**：每笔交易的风险金额不超过账户总值的一定比例（通常 1%–2%）。

**计算公式**：
```
手数 = (账户总值 × 风险比例) / (止损点数 × 每点价值)
```

**示例**：
- 账户 $10,000，风险 1%（即 $100）
- EUR/USD 止损 50 pips，每 pip = $10/手
- 手数 = $100 / (50 × $10) = **0.2 手**

## 分散化原则

- 避免将资金集中在单一品种或高度相关的品种
- 外汇中 EUR/USD 与 GBP/USD 高度正相关，同时重仓等于双倍风险
- 适当分散至不同资产类别（外汇、商品、指数）

## 杠杆控制

- 高杠杆虽然放大收益，也同等放大亏损
- 建议新手实际使用的有效杠杆（净头寸 / 账户净值）不超过 5–10 倍
- 即使平台提供 1:500，也不意味着应该全额使用

## 负余额保护（Negative Balance Protection）

部分监管辖区（EU/FCA）要求零售客户享有**负余额保护**：即强平后账户余额不会变为负数，亏损上限为账户存款。

## 常见风险管理错误

| 错误 | 后果 |
|------|------|
| 不设止损 | 单笔亏损可能毁掉大部分账户 |
| 频繁移动止损 | 失去风险控制意义 |
| 亏损加仓（Martingale） | 短期可能回本，极端行情下爆仓 |
| 情绪化操作（追涨杀跌） | 系统性亏损 |
| 过度杠杆 | 小波动即触发强平 |
