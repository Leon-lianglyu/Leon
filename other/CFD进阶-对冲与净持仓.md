# CFD 进阶：对冲（Hedging）与净持仓

> 🎯 **新人导读**：赠金扣除逻辑中有「对冲关盈利单套利」的特殊处理，MT4 和 MT5 的对冲方式不同也是客户常见疑问来源。

## 什么是对冲

**对冲（Hedging）**：在同一账户上同时持有某一品种的多头（买入）和空头（卖出）仓位，使两个方向的盈亏相互抵消，以降低价格波动风险。

### CFD 对冲示例

```
账户持仓：
  买入（Long）  EUR/USD  1 手  → 价格上涨盈利
  卖出（Short） EUR/USD  1 手  → 价格下跌盈利

净效果：价格无论涨跌，理论上盈亏为 0（完全对冲）
```

---

## MT4 vs MT5 的对冲差异

| 平台 | 对冲支持 | 净持仓显示 | 保证金要求 |
|------|---------|-----------|-----------|
| **MT4** | ✅ 支持同向多单、双向对冲 | 显示每笔独立订单 | 多头和空头各占独立保证金 |
| **MT5** | ✅ 支持（默认净持仓模式） | 净持仓（多空相消后显示） | 通常按净仓量计算（较低） |

> UM 同时提供 MT4 和 MT5，客户可在两个平台上进行对冲操作。

## 对冲与保证金

### MT4（独立仓位模式）
```
买入 1 手 EUR/USD → 占用保证金 A
卖出 1 手 EUR/USD → 占用保证金 B（单独计算）
总占用保证金 = A + B
```

### MT5（净持仓模式）
```
买入 1 手 + 卖出 1 手 → 净仓位 = 0 手
净持仓为 0 → 占用保证金极低或为 0
```

这就是为什么有客户利用 MT5 对冲来维持极低保证金占用的原因。

## 对冲与赠金扣除逻辑（为什么这里重要）

UM 的赠金扣除规则专门针对「对冲中关盈利单出金」的情形：

**场景**：
1. 客户入金 200 USD，获得 200 USD 赠金（总余额 400）
2. 开多头 1 手 + 空头 1 手（完全对冲），净风险为 0
3. 其中一个方向盈利 200 USD，客户**仅平仓盈利单**，申请出金 200 USD
4. 账户仍保留亏损单（持仓中）

**问题**：
- 旧逻辑：赠金只扣 20%，客户实际提走 200 USD 盈利后，亏损单由赠金承担 → 赠金被「套利」
- 新逻辑：系统将亏损持仓计入赠金扣除计算 → 赠金全部扣完

```
新逻辑公式：
扣除赠金 = 亏损金额 / (净值 - 出金额) × 赠金总额

= 200 / (400 - 200) × 200 = 200（全部扣完）
```

## 对冲与黑名单 SOP

UM 的黑名单排查 SOP 中，**异常对冲行为**是触发风控审查的标志之一：

- 同一账户大量对冲订单且频繁只出盈利方向
- 跨账户对冲（两个账户一多一空，套取赠金或返佣）
- 利用对冲绕过出金限制

## 净持仓（Net Position）

**净持仓**：同一品种多头与空头相互抵消后的实际暴露量。

```
净持仓 = 多头手数 - 空头手数

示例：
买入 3 手 EUR/USD + 卖出 1 手 EUR/USD
净持仓 = 3 - 1 = 2 手（净多头 2 手）
```

净持仓的意义：
- 决定实际市场风险敞口
- 影响浮动杠杆分级（见[[CFD进阶-浮动杠杆机制]]）
- MT5 保证金计算基于净持仓

---

## 与跟单（Copy Trade）的关系

UM Social / 专业跟单中，Follower 账户的对冲行为会影响 Provider 的绩效费计算：
- 绩效费基于 Follower **通过订阅开立的仓位**盈亏，不含自行手动仓位
- 但若 Follower 手动开对冲单，可能影响账户保证金，进而影响跟单能力
