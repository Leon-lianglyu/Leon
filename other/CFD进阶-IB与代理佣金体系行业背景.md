# CFD 进阶：IB（介绍经纪人）与代理佣金体系行业背景

> 🎯 **新人导读**：IB 和 CPA 的本质区别、多层返佣结构、归属的行业含义——这是理解 UM 代理体系的行业背景，让 Ch5/Ch6 的内部规则更容易消化。

## IB（Introducing Broker）在行业中的定义

**介绍经纪人（IB）**：不直接执行客户交易，而是将客户**介绍给主经纪商（Carrying Broker）**的中间方。IB 从客户产生的交易量中获得**返佣（Rebate）**，不承担交易风险。

### IB 与 CPA 的本质区别

| 维度 | IB（介绍经纪人） | CPA（Cost Per Action）|
|------|---------------|----------------------|
| 盈利模式 | 按客户**交易量**持续返佣 | 按客户**动作**（首入金）一次性佣金 |
| 佣金时效 | 长期持续（客户一直交易则一直返佣） | 一次性（客户首次满足条件后结束） |
| 适合角色 | 专业代理商、交易社区运营者 | 营销渠道、流量平台 |
| 收入可预测性 | 高（与交易量正相关） | 低（取决于新获客数量） |
| UM 要求 | 需 POI 验证、设置返佣 | 通过 Cellxpert 系统管理 |

## IB 返佣的行业计算逻辑

CFD 行业的 IB 返佣有两种主流方式，与 UM 的 STP/ECN 分类完全对应：

### 1. 点差分润（Spread Share）→ 对应 STP

经纪商将加价点差的一部分（pips）分给 IB：

```
IB 收入（每手）= 客户交易手数 × IB 返点（pips/手）× 点值

例：IB 返点 0.7 pips，客户交易 EUR/USD 1 手
点值 = $10 / pip（标准手）
IB 收入 = 1 × 0.7 × $10 = $7
```

### 2. 手续费分润（Commission Share）→ 对应 ECN

经纪商将固定手续费的一部分（USD/手）分给 IB：

```
IB 收入（每手）= 客户交易手数 × IB 返佣（USD/手）

例：IB 返佣 1.5 USD/手，客户交易 10 手
IB 收入 = 10 × $1.5 = $15
```

### 两种方式不可混用的原因

若 STP 和 ECN 返佣档位不同级（如 STP 属于中档而 ECN 属于高档），等效于 IB 在两种模式下获得不同比例的「经纪商让利」，破坏公平性并增加运营复杂度。UM 要求同级申请正是为此。

## 多层 IB 结构（Multi-Tier IB）

行业惯例允许 IB 在自己下方再发展下级 IB（Sub-IB），形成多层金字塔结构。每一层都从最终客户的交易量中获得对应比例的返佣。

### UM 的层级规则

- 多层 IB 各层设置**相互独立**
- 任何层级的调整都需要提供该层的返佣表
- 代理直客的交易组别跟随直属代理
- **代理层数上限**：由主管控制，有上限限制

### 返佣金字塔示例

```
客户交易 1 手 EUR/USD（STP）

一级 IB（上级）：返点 0.4 pips → $4
二级 IB（中间）：返点 0.2 pips → $2  
三级 IB（直属 IB）：返点 0.1 pips → $1

总让利 = 0.7 pips（含在账户 Markup 中）
```

## TOC（Term & Conditions）规则背景

**TOC 规则**：行业中部分经纪商设置「返佣触发条件」，防止空账户刷佣金或不真实交易。

UM 的 TOC 规则（参见[[IB-返佣计算方式]]）：客户需满足一定真实交易条件才触发 IB 返佣。这是行业反欺诈的常见做法：

常见欺诈场景：
- 客户与 IB 是同一人，开账户只为赚返佣
- 客户只做「假交易」（高频开平对冲）刷量
- 利用奖金账户和返佣套利

## 加点加佣（Markup）的行业逻辑

IB 要求更高返佣时，经纪商通过**增加点差 Markup 或手续费**来覆盖成本：

```
经济逻辑：
经纪商总让利空间 = 固定的（受流动性成本限制）

若 IB 要求高返佣（高档位）：
→ 经纪商需要从客户端多收（加点/加佣）来补偿
→ 客户交易成本上升
→ IB 从每手赚更多，但经纪商收入与无加点时相同

结果：高档位返佣 = 客户支付更高成本 → IB 获益更多
这就是「加点加佣越高，销售手数佣金越低」的根本原因。
```

## IB 与归属（Ownership）的行业含义

「客户归属」在 CFD 行业中是核心利益关系：

- 客户注册时绑定推广链接 → 确定第一归属
- 归属决定哪个 IB 从客户交易中获得返佣
- 恶意抢客（未经同意转归属）属于不正当竞争

UM 的归属转移规则（需证明、48小时确认、原销售批准）正是行业规范化的体现。
