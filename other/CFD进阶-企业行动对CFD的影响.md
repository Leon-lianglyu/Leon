# CFD 进阶：企业行动（Corporate Actions）对 CFD 持仓的影响

> 🎯 **新人导读**：股票/指数 CFD 遇到除权除息时账户会出现神秘调整，这里解释 UM 派息公式，对应 wiki 的「产品-企业行动记录」。

## 什么是企业行动

**企业行动（Corporate Actions）**：上市公司影响其股票价格或股份结构的重大决定，包括：

| 类型 | 说明 |
|------|------|
| **股息（Dividend）** | 公司向股东派发利润 |
| **股票拆分（Stock Split）** | 一股变多股（如 2:1 拆分，价格减半，数量翻倍） |
| **合股（Reverse Split）** | 多股合一股 |
| **分拆（Spinoff）** | 母公司剥离子公司成独立上市公司 |
| **供股（Rights Issue）** | 向现有股东按比例发行新股 |

---

## CFD 持仓在企业行动中的处理方式

CFD 持有者不是实际股东，**不直接参与企业行动**，但经纪商会在账户中做相应调整以反映经济等效效果。

---

## 股息（Dividend）调整

### 原理

股票除息日（Ex-Dividend Date）当天，股价会自动下跌（约等于每股股息），以反映公司已将利润派出。

CFD 持有者不持有实际股票，无法收到真实股息，但经纪商通过**现金调整**来模拟效果：

| 持仓方向 | 处理 |
|---------|------|
| **多头（Long）** | 账户**收到**股息等额现金（正调整） |
| **空头（Short）** | 账户**扣除**股息等额现金（负调整） |

### UM 的计算公式

```
派息金额 = Dividend × Volume（手数）× Contract Size × EoD 价格（汇率换算）
```

**示例（SP500）**：
- Dividend = 0.587
- Volume = 0.2 手
- Contract Size = 1
- USD 账户：EoD = 1

```
派息 = 0.587 × 0.2 × 1 × 1 = 0.1174 USD
```

**示例（HK50，HKD 结算）**：
```
派息 = 派息金额(HKD) × HKD/USD 汇率（≈0.13）
```

### 重要说明

- 股息调整在**除息日前一个交易日收盘后**执行
- Swap Free（NM）账户的指数、大宗商品、加密货币不收取 Swap，但会以**Administration Fee** 形式收取，股息调整逻辑不变
- 派息公告参考：[UM 官网公告](https://www.ultimamarkets.com/cn/announcement/)

## 股票拆分（Stock Split）调整

### 处理方式

当一只股票以 N:1 比例拆分时，CFD 仓位会自动调整：

```
新手数 = 旧手数 × N
新价格 = 旧价格 / N
总价值不变
```

**示例（2:1 拆分）**：
- 原持仓：0.1 手 @ $300 = $30 价值
- 调整后：0.2 手 @ $150 = $30 价值（不变）

UM 将此类事件记录在[[产品-企业行动记录]]中，并在事件前公告处理方式。

## 分拆（Spinoff）

### 处理方式

母公司将子公司独立上市时，CFD 处理比股票更复杂。通常做法：

1. 母公司 CFD 仓位调整（价格扣除子公司价值）
2. 子公司 CFD 可能**暂时设为「仅限平仓」（Close Only）**，待市场稳定后恢复
3. 部分经纪商直接以现金形式补偿子公司价值

### UM 的实践

UM wiki（[[产品-企业行动记录]]）记录：
> 企业行动类型：分拆（Spinoff）

通常处理为「仅限平仓」状态，即现有仓位可平仓但不可新开。

## 对交易者的影响

| 企业行动 | 多头持仓影响 | 空头持仓影响 | 注意事项 |
|---------|-----------|-----------|---------|
| 股息 | ✅ 收到现金 | ❌ 扣除现金 | 空头持股息重的股票有额外成本 |
| 拆分 | 数量增加，价格减半 | 同步调整 | 总价值不变，无需操作 |
| 合股 | 数量减少，价格增加 | 同步调整 | 总价值不变，无需操作 |
| 分拆 | 可能现金补偿 | 同步 | 关注「仅限平仓」通知 |
