# CFD 基础：掉期与隔夜费（Swap）

> 🎯 **新人导读**：Swap 是客户持仓过夜时自动扣取的费用，也是 Swap Free 账户申请的背景知识——客户问「为什么账户多扣了钱」时需要解释。

## 什么是 Swap（隔夜费）

当 CFD 持仓**过夜**（即跨越纽约时间 17:00，通常为 GMT 22:00）未平仓时，券商会收取或支付**隔夜资金利息**，称为 **Swap**（掉期费）或 **Rollover Fee**（展期费）。

Swap 的本质是对**借入资金成本**或**收益**的反映：
- 用杠杆做多某货币 → 相当于借钱买入，需支付利息
- 做空某货币 → 相当于出借资产，可能获得利息

## 外汇 Swap 的计算原理

外汇 CFD 的 Swap 基于两种货币的**隔夜利率差**（Interest Rate Differential）：

```
Swap = 名义价值 × (基础货币利率 - 报价货币利率) / 360 × 方向系数
```

- **做多**：支付基础货币利率，收取报价货币利率（净额可正可负）
- **做空**：收取基础货币利率，支付报价货币利率（净额可正可负）

**注意**：实际 Swap 数值由券商报价，包含**点差溢价**（markup），不完全等于银行间利率。

## Swap 的实际影响

| 情况 | 结果 |
|------|------|
| Swap 为负值 | 从账户扣除（最常见） |
| Swap 为正值 | 存入账户（如做空高利率货币） |
| 周三换仓 | 通常计 3 天 Swap（补偿周末 2 天） |

**三重 Swap 日（Triple Swap Day）**：
- 通常为周三（因结算惯例，周三持仓对应周五结算，再往后 2 天为周末）
- 周三过夜持仓会被收取 3 天的 Swap 费用

## 非外汇 CFD 的 Swap

| 品种 | 计算基准 |
|------|---------|
| 股指 CFD | 基准利率（如 SOFR、LIBOR 替代利率）+ 券商溢价 |
| 个股 CFD | 基准利率 ± 股息调整 |
| 大宗商品 CFD | 各品种独立定价，通常为固定点数 |
| 加密货币 CFD | 通常较高，基于借贷市场利率 |

## 免息账户（Islamic / Swap-Free Account）

为满足伊斯兰教法（Sharia）对禁止利息（Riba）的要求，部分券商提供**伊斯兰账户**（Islamic Account），特点：

- 持仓过夜**不收取 Swap**
- 通常以**管理费**（Administration Fee）或**更宽点差**替代
- 可能限制持仓时长（超过一定天数后开始收费）
- 需要申请，部分券商要求提供伊斯兰信仰证明

> ⚠️ **风险**：部分平台将 Swap-Free 账户作为营销工具，以更宽点差或隐性费用弥补，需注意实际成本。

## 如何查看 Swap 数值

- 交易平台（MT4/MT5）：右键品种 → 查看规格（Specification）→ Swap Long / Swap Short
- 单位通常为：点数（Points）或百分比（% p.a.）
