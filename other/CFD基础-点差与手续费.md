# CFD 基础：点差与手续费

> 🎯 **新人导读**：点差是 STP 账户的主要成本，手续费是 ECN 账户的主要成本，理解这个区别才能向客户解释为何两种账户的费用结构不同。

## 点差（Spread）

### 定义

**点差**是买价（Ask）与卖价（Bid）之间的差值，是 CFD 交易最主要的交易成本之一。

```
点差 = Ask（买入价）- Bid（卖出价）
```

开仓时立即产生的**隐性成本**：做多按 Ask 价买入，做空按 Bid 价卖出，平仓时方向相反，点差是每次交易必然亏损的起始成本。

### 点（Pip）与点差单位

| 品种 | 1 Pip = | 示例 |
|------|---------|------|
| 外汇主要货币对 | 0.0001（第 4 位小数） | EUR/USD：1.1000 → 1.1001 差 1 pip |
| 日元货币对 | 0.01（第 2 位小数） | USD/JPY：145.00 → 145.01 差 1 pip |
| 黄金（XAU/USD） | 0.01 | $1900.00 → $1900.01 差 1 pip |
| 指数 | 通常为 1 个指数点 | |

### 固定点差 vs 浮动点差

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| **固定点差** | 不随市场波动变化，始终固定 | 新闻时段、低流动性时段可控 |
| **浮动点差（Variable）** | 随市场流动性变化，正常时段较窄 | 正常市场更低成本，但极端行情大幅扩大 |
| **最低点差（Raw/ECN）** | 接近银行间点差（可低至 0），另收佣金 | 高频交易者，需配合佣金账户 |

### 点差对盈亏的影响

**外汇示例**：
- EUR/USD 点差 2 pips，1 手（100,000）
- 每 pip 价值 = $10
- 点差成本 = 2 × $10 = $20（开仓即亏 $20）

## 佣金（Commission）

### 何时收取佣金

**STP / ECN / Raw Spread 账户**通常：
- 点差极低（接近 0 或为 0）
- 另外按**手数**或**名义价值**收取固定佣金

**标准账户（Standard Account）**通常：
- 点差已包含利润，**不额外收取佣金**
- 点差通常高于 ECN 账户

### 佣金计算方式

常见计算方式（以外汇为例）：

| 计算方式 | 示例 |
|---------|------|
| 每手固定金额 | $7/手（往返 $14） |
| 名义价值百分比 | 0.005%（1 手 $100,000 = $5 单边） |
| 每百万名义价值 | $50/百万（1 手外汇约 $5） |

## 实际交易总成本

```
总成本 = 点差成本 + 佣金（若有）+ Swap（持仓过夜）
```

**对比示例**（1 手 EUR/USD，价格 1.1000）：

| 账户类型 | 点差 | 佣金（单边） | 单次往返总成本 |
|---------|------|------------|--------------|
| 标准账户 | 1.5 pips = $15 | $0 | $15 |
| ECN 账户 | 0.2 pips = $2 | $3.5 | $9（$2 + $3.5×2） |

## 点差扩大（Spread Widening）

以下情况点差会大幅扩大：
- **重大经济数据发布**（非农、CPI、央行利率决议）
- **市场开盘/收盘**（流动性低谷）
- **低流动性时段**（亚洲早盘、节假日）
- **黑天鹅事件**（Flash Crash、地缘政治冲击）

> ⚠️ 止损单在点差扩大时可能以不利价格成交（滑点）。
